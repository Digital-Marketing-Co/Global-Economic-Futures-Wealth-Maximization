# Global Economic Futures & Wealth Maximization

A comprehensive research and analytical repository dedicated to exploring global economic trends, futures markets, investment strategies, and wealth optimization methodologies.

## Purpose

This repository serves as a centralized knowledge base for:
- **Economic Analysis**: Global economic indicators, trends, and forecasting
- **Futures Markets**: Commodity, currency, and derivatives analysis
- **Wealth Strategies**: Investment optimization and portfolio management
- **Research Documentation**: Academic papers, case studies, and analytical frameworks
- **Data Archives**: Historical economic data and market metrics

### Contributing Research
1. Organize work by category (research, data, analysis)
2. Use descriptive file names and include metadata
3. Document sources and methodologies
4. Commit with clear messages describing changes

### Data Management
- Maintain version control for all datasets
- Include data source documentation
- Archive superseded versions
- Preserve historical records for longitudinal analysis

### Collaboration
- Reference external research with full citations
- Cross-link related analyses
- Maintain consistency in formatting and terminology
- Document assumptions and limitations

## Encyclopedia Publication Program

The current flagship program is an evidence-backed encyclopedia and interactive intelligence platform covering the **249-economy statistical universe**, including sovereign states, territories, and special statistical economies.

Planned deliverables include a unified country-by-country encyclopedia, a global synthesis of fewer than 20 introductory pages, a Next.js/React/TypeScript/Tailwind application, reproducible provenance ledgers, scenario models, and complete publication QA.

Primary and authoritative sources take priority. Missing values will be labeled rather than invented, and century-scale projections will be published as conditional scenarios rather than precise predictions.

See `docs/PROJECT_CHARTER.md`, `docs/RESEARCH_STANDARD.md`, `data/SCHEMA.md`, and `COPYRIGHT.md`.
